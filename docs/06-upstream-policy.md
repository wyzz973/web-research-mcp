# 上游搜索准入规则

用户确认日期：2026-09-08。此规则替代此前“商业免费额度可选、默认关闭”的设计。

## 硬要求

任何实际搜索来源，包括 SearXNG 或其他聚合器背后的引擎，都必须同时满足：

- 普通用户可公开匿名访问。
- 不要求注册、登录或导入登录 Cookie。
- 不要求申请、配置或由第三方代持 API Key；免费 Key 同样不接受。
- 不依赖试用余额、计费额度、信用卡或付费搜索订阅。
- 不依赖付费代理或付费验证码服务才能完成基本搜索。

匿名连接自动产生的普通会话 Cookie、CSRF 参数等不是用户登录凭证；应由适配器管理，不能要求用户手工提供。免费公开 HTTP API 只要符合上述条件，也可纳入；“API”本身并不等于需要 Key。

## 候选与排除

SearXNG 中 DuckDuckGo 等公开网页适配优先接受检查；Google/Bing 等按具体网页接入方式及实测结果判断。Wikipedia 等免 Key 领域搜索可作为补充，不能标成全网搜索。

Brave Search API、Jina Search、Mojeek 付费/试用 API 不接入。其他依赖 Key 的服务即使有免费计划也同样排除。某品牌的网页适配与其商业 API 应分别判断。

## 落地方式

1. 固定 SearXNG 版本，记录精确 engine 名称、代码适配和上游访问方式。
2. 使用显式白名单；未知来源、未知凭证条件默认不可启用。
3. 部署配置关闭白名单外引擎，MCP 请求再次显式指定引擎；升级配置后重做检查。
4. 在无搜索 Key、账号和登录 Cookie 的环境中做真实查询，记录各引擎结果与失败状态。
5. 限流或挑战页出现时，仅退避、切换到另一个合格来源或返回错误，不转入 Key/付费服务。

免费匿名访问是一项准入条件，不是无限请求或全球所有网络均可访问的承诺。要对当前网络实测成功率，并明确返回 RATE_LIMITED / UPSTREAM_BLOCKED。

SearXNG 的本机地址、引擎列表及自身实例 secret 属于部署配置；服务器资源与带宽仍有成本。本规则限定的是上游搜索接入，不表示将自建服务不设限制地公开到互联网。
