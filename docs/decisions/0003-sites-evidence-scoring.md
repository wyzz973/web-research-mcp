# ADR 0003：域范围、原文证据与可解释评分

Status: accepted

Implementation: implemented

日期：2026-09-08。用户要求搜索时可指定 sites/域名，返回原文片段证据、置信度和相关联程度。

## 问题

只有上游 URL、摘要和排名不足以让 LLM 判断结果是否来自指定站点、是否有实际原文支撑，以及评分究竟表示什么。

## 决策

使用结构化 sites 作为域允许清单，保留 include_domains 为互斥同义输入；应用层严格过滤，并约束证据获取的跳转范围。显式 evidence_mode=extract 补抓有界数量的结果，复用已有 fetch 和快照链路。

snippet 与 page_excerpt 分离。每个原文片段必须精确匹配 text 快照，返回 hash、offset、有效期和可供 webfetch 读取的快照 cursor。websearch 编排直接调用领域接口，不嵌套调用 MCP webfetch 协议。

相关性先采用可解释词法覆盖分值；结果级统一基于 title/snippet，片段级独立基于 quote。置信度描述证据可追溯性，事实正确概率保留 null。完整规则归 [功能设计](../12-sites-evidence-scoring.md)。业务契约统一推进为 0.2-draft，同步全部 Schema 和示例。

## 考虑的替代方案

**只向 query 拼接 site:。** 上游支持不同，不能保证最终结果范围；需要独立 hostname 过滤与跳转检查。

**所有搜索默认抓取全部结果。** 放大免费上游和目标站点的请求压力，延迟与失败比例不可控；采用显式模式和预算。

**把 snippet 当证据。** 上游摘要可能截断或重写，无法保证原文定位；只有实际获取且校验后的片段标 page_excerpt。

**把模型相关分数当事实置信概率。** 查询匹配、文本支持和事实真假不同；没有标注与校准之前不输出真假百分比。

## 后果与验证

补抓模式延迟更高，部分失败是正式结果状态。来源范围、引用文本和评分版本必须进入缓存身份。M1 交付域过滤和词法相关性，M2 交付有界正文证据与可追溯置信等级，M3 再评估模型评分，不引入付费或需要 Key 的搜索路径。
