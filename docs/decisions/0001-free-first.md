# ADR 0001：免费、免 Key 的独立搜索工具服务

状态：免费且免 Key 的上游要求已由用户确认；实现选型待 M1 实测验证。日期：2026-09-08。

## 决策

初版采用 TypeScript 薄 MCP 服务，两个基础工具，SearXNG 为默认可配置搜索后端，抓取管线独立。上游搜索限于公开、匿名、免注册、免 API Key、无需付费的访问方式；免费 Key、共享 Key、试用额度均排除，不保留商业 Key 后端开关。模型能力默认关闭。先静态 HTTP，浏览器后备后置。

## 依据与取舍

SearXNG 提供 HTTP JSON 接口，减少独立维护多个搜索网页解析器的工作；但仍需管理实例和上游可用性。[官方 API](https://docs.searxng.org/dev/search_api.html)

Python 的 DDGS、Trafilatura、Crawl4AI 生态很合适，但为了轻量本地 MCP 进程先选择 TS。若基准证明 Python 提取质量有显著收益，可以追加 worker，不改两个公共工具契约。

直接使用现有 mcp-searxng 可快速获得搜索能力；本项目另建边界，是为接入正文快照、统一错误和检索实验。没有 fork 或复制第三方源码，后续若复制需保留许可声明。

不以公开 SearXNG 实例作为默认服务；官方明确指出许多实例禁用 JSON。免费额度 API 不进入任何搜索路径。排序先保留上游结果，待有基准和独立列表再启用融合模型。

## 重新评估条件

当前网络上 SearXNG 可用率不足；TS 提取器保真不达标；目标客户端不兼容 SDK v2；本地精排资源成本超过收益。出现这些证据时更新 ADR，不把当前建议当永久约束。

上述技术调整继续遵守用户确定的免费、免 Key 要求；不能因为某搜索源不可用而自行放宽。
