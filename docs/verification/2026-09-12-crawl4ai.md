# 0.5.0 Crawl4AI 接入验收

日期：2026-09-12。平台：macOS ARM64，Node 24.20.0；Crawl4AI 0.9.3、Python 3.12.11、Playwright 1.62.0 及其管理的 Chromium。独立环境已实际安装，工作台仍在 127.0.0.1:18900，默认搜索引擎 Brave + DuckDuckGo 保持不变。

## 真实交付

webfetch 新增 engine=static|crawl4ai|auto，websearch 的证据提取新增 fetch_engine。默认 static；auto 对静态提取失败或可见 HTML 正文少于 80 字符的结果尝试受控浏览器，不绕过 robots、验证码、私网、HTTPS 降级、超时和资源上限。游标读取不再选择引擎，返回实际 fetch_backend。

Crawl4AI 真正调用 AsyncWebCrawler.arun 执行 JavaScript、取得渲染 DOM；Node 网关提供所有页面/脚本/数据字节；既有 Readability/Turndown 继续规范化输出，SQLite 保存实际渲染正文快照、哈希与 Unicode 偏移。不是仅安装包或用 Playwright 代替 Crawl4AI。

安装命令 pnpm crawl4ai:setup；页面与 trace 页面均可选策略、显示安装状态和实际渲染步骤。未安装时轻量静态路径仍可用，动态请求给出 CONFIGURATION_REQUIRED 安装说明。

## 真实公开网页验证

通过实际 MCP 调用与浏览器工作台请求 https://quotes.toscrape.com/js/：

- static 返回导航文字，未取得 JavaScript 生成的正文。
- crawl4ai 返回实际引用正文，并标明 fetch_backend=crawl4ai。
- auto 对过短静态正文切换至 Crawl4AI，成功返回正文。
- 工作台显式动态模式成功返回 1,064 个字符，Trace ID 68942ab6-eee2-42a4-82ab-c5d35ce0d3b2，记录启动、渲染、资源/robots、规范化提取、快照和分页。
- 不带末尾斜杠的 HTTPS 地址触发上游向 HTTP 的降级重定向，auto 正确返回 FETCH_BLOCKED，没有为了完成抓取放宽策略。

原始 MCP/HTTP 响应保存在本机 ignored artifacts/crawl4ai-2026-09-12/{static,dynamic,auto,auto-final,ui-fetch}.json。公开站点可能随时变化，此观察不代表所有动态网站都能读取。

## 真实浏览器与确定性网关 fixture

pnpm test:crawl4ai 使用真正 Python/Crawl4AI/Chromium，但将 Node 网关的 DNS/transport 替换为可审查的测试网页，不冒充公开互联网：

- JavaScript fetch('/data') 后生成中文和 emoji 正文，验证不是初始 HTML 的占位文字。
- 主文档302通过显式重新 arun 保持逐跳检查，最终URL为 /final；避免 Playwright fulfill重定向漏route。
- 私网解析被拒，传输层未连接私网；POST 与 WebSocket 不交给实际网站。
- 搜索候选 fixture → 实际浏览器 → 正文证据，quote 精确匹配保存的快照范围。
- 快照分页保留 backend/hash/snapshot_id，续读没有新增网络请求。
- 网页执行无限循环脚本时，取消传播并在边界内清理已确认归属的 Python 与独立 Chromium 进程组。

网关独立回归覆盖 public DNS 固定连接、重定向/协议/域限制、robots、字节预算、请求计数、并发和取消；进程回归包含独立 detached 浏览器组、根进程已退出、忽略 TERM 升级 KILL、新 renderer 与无关 sibling 保留。Python 自身 socket.connect 禁止互联网连接，浏览器有拒绝代理兜底，Chromium sandbox 保持开启。

## 检查与发布

完整检查覆盖 strict 类型、type-aware lint、格式、生成 Schema、模块边界、行为测试和真实 MCP 入口。最终测试数量与 CI 结果以交付消息为准。干净 tarball smoke 同时验证：静态入口不需要本机 Python/Crawl4AI，显式动态请求给出安装说明，worker与安装资源随包交付。

新增独立 Linux Crawl4AI CI：安装锁定 Python 依赖与 Chromium，执行同样的真实渲染/策略/分页/取消 smoke；不依赖当时免费搜索引擎可用性。源码、安装脚本与锁文件公开，运行浏览器缓存、原文和私有配置不会上传。

## 限制

只支持匿名 GET 主页面、脚本、样式和数据请求，不支持登录、POST API、iframe 正文、任意交互脚本或 PDF。图片/媒体/字体不加载。子资源重定向保守阻止并报告可能不完整。默认固定等待1.5秒，不承诺捕获任意延迟或无限加载的页面。浏览器截图/递归爬站/LLM extraction 未启用。

Crawl4AI 的原始 Markdown 不直接透传；统一规范化是为了保持现有证据和网络安全契约。进程隔离与 Chromium sandbox 不等于完整容器或操作系统级资源配额。原生支持 macOS/Linux，Linux 需具备浏览器系统依赖和可用的 Chromium sandbox。默认仍为静态模式，用户按任务选择动态或自动。
