# 验证记录

本目录保存已经执行的检查结果。每份记录至少包含：日期、变更范围、运行时/平台、实际命令、结果、证据路径与未验证项。失败或环境不具备要明确记录，不能省略后声称全部通过。

实时网络验证还需记录 SearXNG 版本、配置摘要、实际引擎、查询语言、冷/热缓存和各来源状态。包含查询/正文的材料先脱敏，原始抓取数据放 gitignored artifacts；可提交必要的摘要与确定性 fixture。

回放通过只能证明录制输入下的行为，不能取代当日网络可用性。文档检查不证明 Schema 语义，Schema 检查不证明服务器运行，服务器运行不证明发布安装路径正确。
