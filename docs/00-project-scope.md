# 项目范围

日期：2026-09-08。工作名称：Web Research MCP，目录名 `web-research-mcp`。

## 目标

建立一个独立、可被不同 LLM 客户端调用的联网工具服务：`websearch` 根据查询发现网页，`webfetch` 获取指定网页的可读内容。调用者负责决定下一次搜索、选取页面与组织最终答案，服务负责可靠检索、内容提取与来源证据。

文件级项目包含项目目录、调研、架构、契约、配置和实施清单，以及用户后续要求的技术栈、项目规范、编码规范和工程检查。后续实现已完成两个工具与 SQLite 持久化，自建 SearXNG 已用于匿名联网验证；当前不自动修改用户已有 MCP 客户端配置。实际范围和发布结果见 README 与实施验收。

## 免费的三个层次

| 类型 | 定义 | 项目策略 |
| --- | --- | --- |
| 开源自托管 | 软件可自行部署，仍有机器、带宽和维护成本 | 主路线 |
| 无 Key 网页访问 | 无需注册、登录、API Key 或支付，但网页结构、限流和可达性可能变化 | 符合搜索准入方向，具体适配需实测 |
| 商业免费额度 | 需要账号或 Key，额度和开通条件会变化 | 不符合用户要求，排除接入 |

用户已明确：上游搜索必须让普通用户无需注册、Key 或付费即可使用。此要求覆盖主后端、后备引擎以及聚合服务内部的实际搜索来源，不能由服务端代持 Key 来规避。搜索免费额度服务不再是可选后端。详见 [准入规则](06-upstream-policy.md)。

默认运行不依赖付费 LLM 或托管 embedding。可选本地模型也有内存和计算成本。部署者自己的 SearXNG 管理配置不属于购买上游搜索凭证。

## 第一版范围

- 面向公开 HTTP/HTTPS 内容；HTML、纯文本、Markdown。
- SearXNG 搜索适配、结果去重、上游失败识别。
- 正文与标题、来源 URL、抓取时间、快照哈希、分段定位。
- 限流、缓存、超时、取消、可恢复的部分结果和游标续读。
- 搜索按 sites/域名限定，支持子域和排除；结果相关性解释、有界补抓的原文证据与证据可追溯置信等级。交付阶段和真假概率边界见 [功能设计](12-sites-evidence-scoring.md)。
- 本地 stdio MCP；JSON Schema 校验和 stderr 日志。

后续可选：动态浏览器、PDF、站点专用提取、向量索引、神经精排、远程 HTTP、多租户。

暂不建设全网爬虫与自主全网索引，不把搜索结果摘要当作正文证据，不提供自动生成最终研究报告的第三个大工具。全网索引和检索已抓取的本地资料属于不同数据规模。

## 仍需实测的条件

当前网络到各搜索引擎的可达性；中文与英文结果覆盖；目标 MCP 客户端对 SDK v2 协议的支持；本机模型推理资源；搜索源和抓取输出的实际质量。这些不影响立项，但影响后续默认配置。
