## M1：最小可运行链路

- [x] 核实 Node 24 补丁版本、包管理器和 SDK v2 具体版本及目标客户端支持。
- [x] 完善现有仅文档检查的 package.json，锁定 packageManager/运行依赖，生成 pnpm-lock.yaml；验证 JSON Schema 与 SDK v2 的适配及 wire 类型生成。
- [x] 落实 typecheck、lint、format、Schema、导入边界、回放与构建入口检查，禁止空成功脚本。
- [x] 注册两个工具；tools/list、输入约束、错误 envelope 和 stdout 纯净性验收。
- [x] 以操作员配置地址接入自建 SearXNG，明确 json 配置；固定镜像版本或 digest。
- [x] 按上游准入规则检查精确引擎清单；没有搜索账号、Key、登录 Cookie 或付费代理时完成真实搜索。主路径与后备路径均排除免费 Key 和代持 Key 的服务。
- [x] search 状态映射、URL 去重、保留聚合名次。
- [x] sites/include_domains 互斥、域范围规范化、子域与排除语义、上游查询约束和候选应用层过滤；结果附 lexical_coverage_v1 的相关性说明。
- [x] 在预算内采集、过滤后冻结候选池再分页；分支失败/预算不足不误报 empty，cursor 不指向未知上游页。
- [x] 受控 HTTP 抓取、可终止 worker 中的静态正文提取、Markdown/文本输出与 deadline。
- [x] 基础网络验证与抓取同交付：SSRF、DNS 固定连接、跳转/HTTPS 降级、压缩大小、取消、parser worker 超时、挑战页、429 与 robots 策略；通过后才做真实抓取验收。
- [x] 直接实现 SQLite SnapshotStore，进程重启仍可读取有效游标。
- [x] 使用真实 MCP 客户端搜索一个问题，fetch 命中来源，确认原文支撑回答。

完成定义：保存脱敏工具请求/响应、来源 URL 和运行版本；有结果不等于每个引擎都成功。报告实际网络、日期和搜索后端，不能用 fixture 代替 live 证明。

## M2：可靠性与正文证据

- [x] 快照持久化、稳定段落 offsets、带有效期的游标续读。
- [x] 进程重启后，在有效期内继续读同一快照；过期明确报错。
- [x] 并发、进程关停、取消和资源清理的针对性回归。
- [ ] 多日运行与持续压力测试（尚未执行）。
- [x] 提取保真：中文、英文、代码块、表格、导航密集页、超长文档。
- [x] TTL、stale 标记、上游失败与空结果区分、stderr 脱敏日志。
- [x] evidence_mode=extract 的有界前 N 条补抓、逐跳域范围、原文 text 快照、片段 hash/offset/snapshot_cursor 与证据完成状态。
- [x] 结果与片段 relevance 分开标 basis，traceability_v1 置信等级明确原因，fact_probability 始终 null；部分补抓失败仍返回合法结果和 partial。

完成定义：引用定位可从返回片段复核到保存快照；分页拼接等于完整提取内容，刷新生成新版本；安全和失败用例不能静默成功。

## M3：召回与排序实验

- [x] 构造至少 50 条中英文查询：精确查找、概念、错误码、版本、时效、对比、中文短词。
- [ ] 冻结查询和候选池，用 0/1/2 相关性标签人工评判，记录评判者和日期。
- [ ] 对照 A：SearXNG 原排名；B：去重；C：有真实独立列表的 RRF；D：加本地 BM25；E：加向量/本地精排；F：加 MMR。
- [ ] 同一候选池离线比较排序，同一网络时间窗重复在线采样；区分网络与模型差异。
- [ ] 仅在相关性收益和资源预算都达标时启用额外模型。

## M4：扩展能力

动态浏览器、PDF 与其他媒体、多后端降级、领域搜索源、Streamable HTTP、认证与多租户。所有搜索后端继续受免 Key 准入约束；远程 MCP 自身的访问认证与上游搜索凭证分开。每项独立验收，不用抓取兜底掩盖基础提取失败。

## 0.3.0 的 P0–P3 交付边界

- P0：进程内逐引擎状态、冷却/半开恢复、只读观察及显式 search:doctor；不把一轮采样冒充多日稳定性测试。
- P1：56 条中英文查询目录、低频真实 MCP 录制、冻结候选哈希、显式 Agent/人工标签格式、离线比较报告；本轮标注者为 Agent，人工金标仍未完成。
- P2：可选 BM25/BM25+MMR 在冻结前重排，保留原名次与评分版本。默认 upstream；无逐引擎独立列表时 RRF 不进入在线路径。模型排序仍未启用。
- P3：本地工作台可操作搜索、查看原文/续读/来源声明、错误与引擎诊断、实际评估报告。仅监听 loopback。

本轮实际数量、质量结论与运行证据见版本验证记录；不能将新增运行功能等同于完成未执行的人工标注、多日压力测试或向量模型评估。
