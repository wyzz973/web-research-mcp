# 搜索验收工作台

类型：使用指南。此目录是无额外前端依赖的中文本地工作台，使用 HTML、CSS 和浏览器原生 ES module；同源 Node 服务负责调用现有搜索/抓取服务。不能仅用静态文件服务器打开，因为 API 与请求校验依赖工作台服务。

## 启动

在项目根目录，先完成 [原生 SearXNG 安装](../deploy/native/README.md) 和 `pnpm install --frozen-lockfile`，再执行：

```sh
pnpm searxng:start
pnpm workbench
```

打开命令输出的本地地址。工作台仅供本机验收，不是面向公网的多用户网站。关闭时在启动终端按 Ctrl+C；SearXNG 是独立服务，需要停止时执行 `pnpm searxng:stop`。

## 验收流程

1. 输入问题；可以填多个域名，用逗号、中文逗号或空格分隔。域范围包含子域，由服务端校验及最终过滤。
2. 选择上游顺序、BM25 或 BM25 + 多样性；默认提取前 3 条结果的原文，受服务端预算约束。可关闭提取只看搜索摘要。
3. 点击结果标题或“检查证据”，右栏显示原文、字符范围、快照 hash、抓取时间、选段依据和评分依据。移动端证据栏在结果列表下方，点击后移到该栏。
4. “读取这份完整快照”读取连续文档；“更多相关原文”读取选段计划。二者的分页不能互相替代。继续读取使用原始游标，不重新抓取网站。
5. 尚未抓取的来源可点击“抓取网页原文”；这会通过受控 webfetch API 请求网站，不把摘要冒充原文。
6. 检查来源的真实 hostname、最终 URL、canonical 声明、图标来源、logo 和抓取日期。未知字段显示未提供；图标加载失败显示域名字母，资源 URL 不保证可访问。
7. 查看引擎观察与质量评估；错误、部分结果、上游封锁和未测指标都有单独说明。可以展开对应 JSON 复查原始响应。

搜索和原文读取都可以取消。切换来源会取消旧读取并阻止迟到结果覆盖当前来源；新搜索会取消旧搜索。页面关闭时取消仍在进行的搜索和读取。

## 展示语义

结果相关性仍显示 public relevance 的词法覆盖值，排序实验的分值/依据另见来源 JSON。溯源 high 表示证据具有较强可追踪依据，绝不是事实正确概率；完整快照中精确匹配也不能替代事实核查。

评估面板显示查询目录、已采集和已标注数量，以及同一候选池上的 nDCG@10、池内 Recall@5 与排序 P95 延迟（MRR 保留在 JSON 中）。缺少标注的指标为未测；Agent 标注不是人工金标，离线比较不保证实时上游可用，候选池召回率不等于全网召回率。

## 前后端约定

服务端在 HTML 的 `meta[name=workbench-token]` 中注入本次工作台随机令牌。浏览器仅向同源 `/api/*` 请求发送 `X-Workbench-Token`，不会把它添加到来源链接或图片。令牌不放 URL，也不写浏览器持久化存储；它只保护本地工作台调用，不是搜索 API Key。

| API                 | 用途                                               |
| ------------------- | -------------------------------------------------- |
| GET /api/status     | 本地配置和引擎观察；没有观察不伪装为健康           |
| POST /api/search    | 直接提交 websearch 输入，返回业务 wire output      |
| POST /api/fetch     | 直接提交 webfetch 输入或游标，返回业务 wire output |
| GET /api/evaluation | 最近的本地评估报告；不存在则 available=false       |

上游文字、原文和 JSON 均使用 DOM textContent/text 节点渲染，不解析成 HTML。外部链接只允许不含用户凭据的 HTTP(S)，新窗口带 noopener/noreferrer；图标使用 no-referrer。工作台不引入第三方字体、脚本、分析或 favicon 服务。

前端 API 调用失败不会替换成演示数据。所有示例按钮只填入查询条件，由用户提交后实际搜索。
