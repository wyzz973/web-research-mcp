webfetch 用什么技术？为什么不一定能读取每个网站？

Node.js + Undici 发 HTTP 请求；DNS 与跳转检查约束实际连接，robots-parser 检查抓取规则。独立 worker 内，JSDOM 解析 HTML，Mozilla Readability 提取正文，Turndown 转为 Markdown；SQLite 保存正文快照和续读位置。

它不会运行网页 JavaScript。验证码、robots 禁止、超时或必须动态渲染的页面可能无法读取；失败会保留在记录中，不会把搜索摘要冒充原文。

提交会实际访问上游。重复点击将取消上次调用并开始新调用；逐步回看只读记录，不重发搜索。
